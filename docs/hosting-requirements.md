## Minimum set to check BEFORE uploading

1. PHP 8.3 or newer selected for the domain.
2. The 13 extensions above plus `pdo_mysql` ticked.
3. Database created (utf8mb4) and its server version read in phpMyAdmin (MariaDB 10.3+ or MySQL 5.7+; MySQL 8.0.16+ preferred).
4. `open_basedir` does not block the folder above `public_html`.
5. SSL active and Force HTTPS on.
